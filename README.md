> A production-grade multi-tenant RAG pipeline for restaurant chains

- 🔍 **Hybrid search** combining dense + sparse retrieval for precise answers
- 🏗️ **Multi-tenant architecture** — isolated knowledge bases per restaurant
- ⚡ **Real-time Q&A** over menus, FAQs, and operational docs
- 🧩 Built with **LangChain + Supabase + Vector DB + Embeddings**
